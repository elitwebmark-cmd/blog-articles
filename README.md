# Elit-Web · Блог · квартальний звіт

Звіт (`public/index.html`) і мінімальний Node-сервер без залежностей.

## Теги та коментарі
- Біля кожної статті є вибір тегу та поле для коментаря. Все зберігається автоматично.
- Фільтр «🏷 Всі теги», перемикач «⇅ Сорт. за тегом» і кнопка «🏷 Теги» з'являються в панелі фільтрів.
- Сторінка `/tags`: створення, перейменування, колір, порядок і видалення тегів, а також резервна копія JSON.
- Дані прив'язані до **URL статті** і зберігаються окремо від коду, в `annotations.json` у папці даних.
  Тому їх не зітре ні редеплой, ні заміна звіту новим `index.html`.

## Оновити звіт
Замініть `public/index.html` новим файлом, зробіть commit і push. Сервер сам підключить теги й коментарі
(`annotations.js` / `annotations.css`), тож у новий файл нічого додавати не треба.

## Railway — ОБОВ'ЯЗКОВО Volume
Без Volume файл даних живе всередині контейнера і зникає при кожному деплої.
1. У сервісі: **Settings → Volumes → New Volume** (або правий клік на сервісі → Attach Volume).
2. Mount path: `/data`.
Сервер сам підхоплює `RAILWAY_VOLUME_MOUNT_PATH`. Перевірка: `/health` має показати `"volume": true`.

Сервер щодня кладе копію в `<volume>/backups/` і тримає останні 30 днів.

## Необов'язково: пароль
Змінна оточення `BASIC_AUTH=логін:пароль` закриває весь сайт паролем.

## Локально
`npm start` → http://localhost:3000 (дані зберігаються в `./data`)
